# My Personal Hub — Production Web Application

A cloud-synchronized, modular web application and portfolio management system connected directly with Google Drive and Google OAuth 2.0.

## 🚀 Live Public Website
- **Public URL**: [https://arthanareeshwaran-14.github.io/personal-hub/](https://arthanareeshwaran-14.github.io/personal-hub/)

## ✨ Key Features
- 🌐 **Commercial Google OAuth 2.0**: Published "In Production" authentication supporting all Google users.
- 📁 **Drive Vault**: Direct Google Drive integration using RFC 2387 multipart binary uploader with dedicated folder hierarchy.
- 🎨 **Theme Morph Engine**: Dynamic theme switching with smooth, radiant morph animations.
- 👤 **Personal Info & Profile**: Custom hero banner, avatar, audio player, unique case-sensitive `@handle`, and official Digital Identity Cards.
- 🛠️ **Portfolio Studio**: Interactive portfolio builder with live preview mode and Drive persistence.
- 🎯 **Future Roadmap & Tasks**: Milestone planning, Pomodoro focus timer, and subtask tracking.
- ⚡ **Lightning Fast**: Built with React 19, Vite, Framer Motion, and Lucide Icons.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
